# Word of Life · Bible Word Journey

A phone-first word game with 25 handcrafted puzzles across five illustrated chapters. Drag across letter circles or tap them one by one. Duplicate letters are separate selectable circles, and two-letter answers work the same way as longer answers. The game keeps progress on the current device and offers hints, gentle sound, an optional read-aloud story card, replayable chapters, and a daily puzzle drawn from the handcrafted collection.

## Play

Open `index.html` in a browser or serve this folder as a static website. Start with puzzle 1. Find every word on the board to reveal its short story and Scripture reference. The references invite families to read the passage; the story sentences are paraphrases, not Bible quotations.
